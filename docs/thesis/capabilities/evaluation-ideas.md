# Evaluation ideas

Potential dependent measures:

- correct capability selection and parameterization;
- missing, redundant and repeated capability calls;
- point-in-time and evidence validity;
- numerical and schema correctness;
- material finding coverage and unsupported-claim rate;
- human usefulness, acceptance and override;
- latency, model tokens and monetary cost;
- exact-memory reuse rate;
- effect-policy violations and appropriate abstention.

Experiments can fix context and capability versions while varying the agentic
framework, or fix the agent and context while varying capability versions and
packages. These are different comparisons and should not be conflated.

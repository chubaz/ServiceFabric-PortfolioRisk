# Agent-capability behaviour

Agents should receive a compact ranked capability index first. Full schemas,
examples and receipts are loaded only after a candidate is selected. Every
selection, substitution, preparation step, invocation and reuse decision is a
reviewable event.

Agents may submit capability-improvement or new-capability proposals. Runtime
agents do not write source code or publish definitions. A human-approved
proposal may later be handed to a development-only Studio-Codex session.

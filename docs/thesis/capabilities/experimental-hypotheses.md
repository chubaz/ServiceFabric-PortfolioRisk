# Experimental hypotheses

Candidate hypotheses to refine before experimental registration:

1. Reuse-first capability discovery reduces redundant tool calls and input
   tokens without reducing material finding coverage.
2. Typed preparation chains reduce capability failures and unsupported claims
   compared with direct agent parameterization.
3. Exact capability memory reduces latency and cost when portfolio, as-of,
   dataset revision and parameters are identical.
4. Bounded agent-backed interpretation improves human usefulness only when a
   deterministic value gate admits non-trivial evidence.
5. Capability packages improve agent selection consistency, while excessive
   package size may increase irrelevant calls and coordination error.

# Capabilities in the thesis

This folder retains research questions, hypotheses and design observations
about capability use in agentic portfolio-risk systems. It contains no private
datasets, provider payloads or generated experimental results.
These files are thesis research notes, not canonical runtime contracts.

The central thesis purpose is to distinguish the contribution of an agentic
framework from the contribution of the deterministic, quantitative,
retrieval, interpretation and presentation capabilities it can invoke.

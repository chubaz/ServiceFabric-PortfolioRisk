## Rules

- The Planner may add or refine ideas and record where they came from.
- It may attach exact saved Library items but cannot change them.
- Missing items become Build Requests only after human approval.
- An agent setup can run only when every required check passes.
- Starting a formal comparison fixes exact versions, dates, data, labels, budgets and evaluation measures.
- Results never rewrite the setup used by completed runs.

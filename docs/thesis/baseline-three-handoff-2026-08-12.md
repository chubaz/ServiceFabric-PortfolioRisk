# B0/B1/A1 baseline experiment handoff

## Retained experiment

- Experiment: `experiment.baseline-three-20260812-final`
- Analysis artifact: `counterfactual-analysis:experiment.baseline-three-20260812-final:ef3169804666d1d028fc`
- Case: diversified portfolio, 2017-12-01
- Matrix: one matched B0 Run, one B1 Run and one A1 Run
- Retained outcome: complete and archive-ready, with methodological and execution limitations

## What happened

All three planned Runs completed and produced the common `ArchitectureOutput`.
The Case, mandate, point-in-time boundary, data revision and evaluation protocol
were held constant. The retained outputs agreed on two mandate findings: the
cash reserve and largest-issuer limits required review. B0, B1 and A1 therefore
made the same monitoring and portfolio-review proposal under the currently
available deterministic reference.

B1 made one model call and A1 made four. Both model treatments initially failed
the deterministic semantic critic because their structured claims did not copy
the governed metric and evidence identifiers exactly. The execution wrapper
correctly rejected those interpretations, retained the deterministic mandate
findings and created an abstained model interpretation. No unsafe or invalid
model claim entered `ArchitectureOutput`.

One of eight holdings had no eligible CRSP valuation on the selected date. The
missing holding was Franklin Wireless Corp. No price was imputed; portfolio
metrics and mandate findings were explicitly marked partial.

## What worked

- The 3/3 Run matrix completed with no missing or confounded cell.
- Every Run produced a mapped, effect-free `ArchitectureOutput`.
- All nine evaluation dimensions were present and honest unavailable states were retained.
- Evidence citations resolved structurally.
- Replay time remained frozen during model and capability processing.
- Processing time, calls, tokens and cost were retained.
- Repository integrity checks passed.
- The semantic critic prevented invalid model references from entering the evaluated output.

## What did not work in the retained experiment

- B1 and A1 did not contribute an admitted narrative interpretation because their final model outputs failed semantic verification.
- The missing historical valuation reduced portfolio-observation completeness.
- Detection and severity scores measured preservation of deterministic mandate findings, not independently labelled event relevance.
- Decision quality measured policy agreement only; financial regret was unavailable.
- Confidence calibration, robustness and stability were not fully measurable.
- Current holdings were retrojected into the historical date, so the Run is apparatus evidence rather than a thesis-valid historical portfolio-construction test.
- Daily prices cannot identify intraday market reaction or exact alpha decay.

## Immediate corrections completed

1. The model response schema now enumerates the exact governed metric, event,
   evidence and position identifiers available to each call.
2. The A1 final agent now receives a compact authoritative catalogue. It does
   not receive duplicated event text or other prompt-injection-bearing content.
3. The output contract is bounded to a concise number of claims, references,
   uncertainties and next steps instead of increasing the token ceiling.
4. Missing position diagnostics now retain the affected company name and state
   explicitly that no eligible valuation was available or imputed.
5. The prompt registry and digests were advanced with the revised instructions.

Unsaved same-Case regressions verified the correction:

- B1: one successful model call, semantic critic passed, no provider warning,
  no execution error, and the Run was engine-ready.
- A1: four successful model calls, semantic critic passed, no provider warning,
  no execution error, and the Run was engine-ready.

These regressions do not rewrite the retained experiment and are not themselves
research results.

## Next development sessions

1. Create a point-in-time portfolio-construction rule so every historical Case
   contains only securities eligible on its formation date.
2. Admit independently reviewed event-relevance and severity labels that are
   never visible to B0, B1 or A1 during execution.
3. Add repeated identical Runs and controlled perturbation Cases for stability
   and robustness measurement.
4. Mature decision branches over declared horizons to calculate regret and
   end-of-day execution consequences.
5. Add calibrated probability outputs only where a forecast target and outcome
   label are defined; keep ordinal confidence separate.
6. Reduce model input size by supplying compact evidence catalogues and
   retrieval-selected event subsets while preserving the same evidence boundary.
7. Rerun the matched B0/B1/A1 experiment over multiple dates and Cases after
   the portfolio and label gates are satisfied.

## Interpretation boundary

The retained experiment proves that the execution, mapping, safety and
evaluation plumbing can complete a matched architecture comparison. It does not
yet show that an agent architecture is more accurate, robust or financially
valuable than the deterministic baseline.

# ADR 0007: thesis agent architecture experiment

## Decision

Compare B0, B1, and A1 over one immutable, governed context with a shared
strict output contract and deterministic critic. Use the existing role cards;
do not change product agent authority. Curated point-in-time events replace a
live-news connector. Real model calls are explicitly local and cannot fall
back to fixture responses.

## Consequences

The public suite is reproducible and network-free. Day 3 measures no outcome
quality; historical evaluation is deferred to Day 4.
